Privacy policy

How information submitted through this website is intended to be handled.

Draft for business review. Update this notice to reflect the final hosting, Microsoft 365 and retention configuration before collecting customer data.

Information we collect

If you submit an order or enquiry, the website asks for relevant contact details, a payment transaction reference for the selected sourcing service, and information about the products or services you requested. Never submit a payment PIN, one-time password, card security code or banking password.

How information is used

Submitted details are used to respond to enquiries, confirm product availability, discuss delivery and payment, and manage order requests. Once configured, order and enquiry data is sent through a secure server integration to a Microsoft Excel workbook hosted in the business's Microsoft 365 environment.

Storage and access

The public website must not contain Microsoft credentials or the private automation URL. Access to the workbook and automation should be restricted to authorized business users. The business should set an appropriate retention period and protect its Microsoft account with strong authentication.

Browser storage

The shopping bag and wishlist are stored in the visitor's browser for convenience. They are not the permanent order database and can be removed by clearing browser data.
